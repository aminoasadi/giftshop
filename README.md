# وب‌اپ فروشگاه گیفت‌شاپ اعتباری

این پروژه یک وب‌اپ فارسی و راست‌چین برای فروشگاه هدیه است. کاربر کد شارژ پنج‌کاراکتری روی کارت یا اسکناس فیزیکی را وارد می‌کند، کیف پول اعتباری او شارژ می‌شود و خرید محصولات فقط از همان اعتبار انجام می‌شود.

نام برند، متن‌ها، رنگ‌ها و اطلاعات تماس در `lib/config.ts` متمرکز شده‌اند.

## معماری

- `Next.js App Router` برای صفحات و APIها
- `TypeScript` برای تایپ‌پذیری کامل
- `PostgreSQL` و `Prisma` برای مدل داده و تراکنش‌های اتمیک
- `NextAuth` با ورود ایمیلی OTP برای کاربران و ورود رمزدار برای ادمین
- `Tailwind CSS` برای رابط فارسی، RTL و واکنش‌گرا
- سرویس‌های تراکنشی در `lib/services`
- قواعد دامنه تست‌پذیر در `lib/domain`

## مدل‌های اصلی دیتابیس

- `User` و نقش‌های `USER` / `ADMIN`
- `Wallet` و `WalletTransaction`
- `RechargeCode` و `RechargeAttempt`
- `Product`، `ProductImage` و `Category`
- `Order` و `OrderItem`
- `Address`
- `AdminAuditLog`

## مسیرهای اصلی

- `/` صفحه اصلی فروشگاه
- `/products` فهرست محصولات با جست‌وجو، فیلتر و مرتب‌سازی
- `/products/[slug]` جزئیات محصول و فرم ثبت سفارش
- `/login` ورود
- `/dashboard` پروفایل کاربر، شارژ کیف پول، تراکنش‌ها و سفارش‌ها
- `/terms` قوانین اعتبار و ارسال
- `/admin` داشبورد مدیریتی محافظت‌شده
- `/api/recharge/redeem` مصرف کد شارژ
- `/api/checkout` ثبت سفارش با کیف پول
- `/api/admin/stats` آمار مدیریتی

## برنامه پیاده‌سازی

۱. ساخت اسکلت Next.js، Prisma، Tailwind و تنظیمات برند.  
۲. طراحی مدل دیتابیس برای کیف پول، سفارش، کد شارژ و لاگ مدیریتی.  
۳. پیاده‌سازی سرویس‌های اتمیک شارژ کد، خرید و لغو سفارش با بازگشت اعتبار.  
۴. ساخت رابط فارسی و راست‌چین با ظاهر دیپ‌بلو، کارت‌های شیشه‌ای و دارایی‌های محلی.  
۵. افزودن داده‌های اولیه، README و تست‌های ضروری دامنه.

## اجرای محلی

ابتدا وابستگی‌ها را نصب کنید:

```bash
npm install
```

فایل محیطی را بسازید:

```bash
cp .env.example .env
```

سپس مقدار `DATABASE_URL` و `NEXTAUTH_SECRET` را در `.env` تنظیم کنید.

دیتابیس و داده‌های اولیه:

```bash
npm run prisma:migrate
npm run prisma:seed
```

اجرای پروژه:

```bash
npm run dev
```

## ورود نمونه

ادمین:

- ایمیل و رمز را در `.env` با `ADMIN_EMAIL` و `ADMIN_PASSWORD` تنظیم کنید، سپس `npm run prisma:seed` را اجرا کنید.

کاربر نمونه:

- ایمیل: `user@example.com`
- رمز عبور: `User12345!`

مسیر پنل ادمین پس از ورود: `/admin`

## کدهای شارژ نمونه

- `12345` با ۵۰۰ اعتبار
- `908172` با ۲۵۰ اعتبار
- `66001` غیرفعال
- `777888` منقضی
- `54321` استفاده‌شده

ورودی کد، اعداد فارسی/انگلیسی و حروف لاتین را می‌پذیرد.

## تست‌ها

```bash
npm test
```

سناریوهای پوشش داده‌شده:

- شارژ موفق کد معتبر
- رد کد استفاده‌شده، غیرفعال، منقضی یا بدفرمت
- خرید با اعتبار کافی
- جلوگیری از خرید با اعتبار ناکافی
- بازگشت اعتبار پس از لغو سفارش
- جلوگیری از بازگشت چندباره اعتبار سفارش

## نکات امنیتی

- مصرف کد شارژ در تراکنش دیتابیس انجام می‌شود.
- وضعیت کد با `updateMany` شرطی تغییر می‌کند تا مصرف هم‌زمان یک کد ممکن نباشد.
- مقدار اعتبار از دیتابیس خوانده می‌شود، نه ورودی کاربر.
- تلاش‌های ناموفق شارژ ثبت می‌شوند و محدودیت تلاش برای کاربر و IP وجود دارد.
- خرید و کسر اعتبار در یک تراکنش انجام می‌شود.
- سفارش لغوشده فقط یک‌بار اعتبار بازگشتی دریافت می‌کند.
- تراکنش‌های کیف پول حذف فیزیکی نمی‌شوند.
